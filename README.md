# Chemistry Weekly Quiz Web App (V1.0)

A zero-cost, maintenance-free Chemistry Quiz System built natively on Google Apps Script and Google Sheets.

### Core Features
- **Server-Side Grading:** Answer keys are never transmitted to the client frontend.
- **Auto-Email Dispatch:** Full report sent directly to the student's email on submission.
- **Single-Attempt Guard:** Re-attempt prevention checking `Test ID + Student ID`.
- **Topic Analytics:** Auto-calculates strong and weak chemistry topics.
- **Mobile First:** Responsive CSS with question-palette navigation.
